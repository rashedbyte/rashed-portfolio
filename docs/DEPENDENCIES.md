# Project Dependencies & Architecture

## Core Stack
- **React (`react`, `react-dom`)**: Core UI library.
- **Vite (`vite`)**: Extremely fast frontend build tool.
- **TypeScript (`typescript`)**: For static typing and better code quality.
- **React Router (`react-router-dom`)**: For client-side routing and SPA navigation.

## Styling
- **Tailwind CSS (`tailwindcss`, `postcss`, `autoprefixer`)**: Utility-first CSS framework for rapid UI development.
- **Lucide React (`lucide-react`)**: Lightweight and customizable icon library.


## Animation and effect 
- **React Type Animation (`react-type-animation`)**: For dynamic typing effects in the Hero section.
